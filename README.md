# Sales Dashboard 📊

A simple interactive sales dashboard built with **Power BI** to explore sales data and understand business performance.

## About the Project

The dashboard provides a visual overview of sales data and helps identify trends, differences, and patterns across the data.

## What I Analyzed

* Overall sales performance
* Sales trends over time
* Sales by category
* Sales by region
* Key performance indicators (KPIs)

## Tools

* Power BI
* Power Query
* DAX

## What I Worked On

In this project, I practiced:

* Cleaning and preparing data
* Creating calculated measures
* Building interactive visuals
* Designing a clear dashboard
* Analyzing and presenting data insights
